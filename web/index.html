5 个步骤

  1. 选择一个带错误的样例

    进入编译诊断，在“选择样例”中选择“类型不匹配”。先看到的是已采集的诊断记录，第 2 行把字符串 "three" 赋给了整数类型 Int64。

    样例第 2 行let count: Int64 = "three"

  2. 可选：在本机重新编译

    环境显示“本机编译已就绪”后，点击“编译所选样例”。这个样例出现“编译未通过”是预期结果，说明编译器发现了其中的错误。

    按钮不可用时，可以跳过这一步，直接阅读已采集的报错。需要排查时再展开“环境详情”。

  3. 点击报错位置，回到代码

    点击诊断卡片中的“第 2 行 · 24 列 ↗”，编辑器会选中对应位置。此时先保持源码不变，继续查找依据。

  4. 查阅官方文档

    本机核心就绪时，进入文档依据，关键词留空，点击“检索文档”。系统用当前报错检索本机仓颉 1.0.5 文档摘录；阅读原文与来源，核对类型规则。

    检索不可用时，可先阅读本页的类型错误讲解，再练习修改。检索结果不会自动修改代码。

  5. 修改、核对，再保存

    回到编译诊断，将 "three" 改为 3，展开“查看修改并保存”。核对差异和所附的原诊断文档，再确认保存。进入记录与报告，在已保存修改中展开“记录信息与导出”，下载可读修改报告 HTML，即可回看差异、摘录和来源。

    保存本身不会编译或测试。原编译日志可单独导出，任务历史可回看真实样例编译；后续公开测试需要配置好的 Linux 容器环境。

遇到问题时

常见问题

“编译所选样例”是灰色的，怎么办？

在编译诊断页展开环境详情，查看提示并点击“检查环境”。本机需要仓颉 SDK 1.0.5 和 Doctor 核心就绪；编译进行中也不能重复提交。若刚导入了文件或修改了副本，请重新选择一个内置样例；编辑内置样例后，也可以点击“恢复记录副本”。

修改后，怎么验证自己的程序？

在编译诊断页编辑或导入 .cj 副本，展开“查看修改并保存”，核对差异后确认保存。再进入“测试验证”，选择这份已保存修改，填写程序输入和期望输出，点击“编译并验证这份修改”。这需要已配置的本地 Linux Docker 环境；本机未就绪时会显示原因并禁用按钮。验证始终使用你选择的已保存版本，不会替换编辑框。每次测试按原始字节比较输出，包含空格与换行；程序使用 println 时，期望输出通常需要勾选末尾换行。这里只验证公开测试，不代表所有输入或保留测试都通过。

修改源码后，为什么原诊断与检索不能继续定位？

修改后，旧诊断仍对应原文，因此定位与文档检索暂停，文档页清除当前结果。先前完成的检索可以在“查看修改并保存”中作为原诊断参考附带，也可以取消勾选；它不代表对新代码的诊断。“恢复记录副本”只恢复编辑框中的原文，已保存修改与报告仍保留。切换原诊断或导入源码会清除当前参考选择。

几个下载按钮有什么区别？JSON 都能重新打开吗？

“下载当前副本”保存正在编辑的 .cj 源码；“导出当前诊断记录”保存采集时的源码与编译日志，可通过“打开诊断记录”再次载入。检索证据、任务记录和修改记录 JSON 用于分别留档，不能作为诊断记录导入。可读修改报告 HTML 包含人工确认的差异、原诊断与所附文档；独立验证报告再记录公开测试及实际结果，两者都可离线用浏览器阅读。已保存修改、验证报告和材料包 JSON 可在“记录与报告 → 已有报告回看”打开；单独诊断 JSON 用“记录与报告 → 当前诊断原始记录”中的导入入口。

检索不到文档，是不是说明代码没有问题？

不是。目前只检索本机 15 段仓颉 1.0.5 官方文档快照，可以尝试“类型”“函数”等关键词。没有命中只说明这次查询没有找到相关摘录。检索需要本机核心就绪；点击来源链接查看完整原文时需要联网。

显示“编译通过”，就说明程序做对了吗？

编译通过只说明这次编译没有报错。编译诊断页的审核样例只编译、不执行，仍标记“行为未验证”。测试验证页的独立容器验证会运行你提供的公开测试；即使显示“公开测试通过”，结论也只适用于这份已保存源码和这些输入，不能据此宣称修复完全正确或 A/B 实验有效。

切换页面、刷新或关闭后，我的内容还在吗？

使用侧栏切页会保留当前副本、诊断与检索结果。刷新或关闭后重新载入默认样例。未保存编辑可能丢失，离开前会提示；请先确认保存修改，或下载需要保留的副本。已确认的修改存于本机，重新打开后到“记录与报告”载入。已保存到本机的编译任务可在“任务历史”中查看，浏览样例、导入记录和文档检索不会新增编译任务。

    第一次用 API Key？看看填写说明
    从哪里获取？
    在你选择的模型服务商开发者控制台创建密钥，并复制其基础地址和模型 ID。聊天网站的登录密码不能当作 API Key。
    接入后会发送什么？
    计划在请求前展示当前代码、报错和所选文档范围，由用户确认后发送给所填服务。费用由该服务商按你的账户计费。
    可以给别人用吗？
    使用者填写自己的密钥即可配置各自服务。不要共享密钥；演示或截图前可点击“清空配置”。当前页面还不会发送请求。
