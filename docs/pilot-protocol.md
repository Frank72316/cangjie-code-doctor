# 首轮完整 A/B 先导实验：生成前登记

登记日期：2026-11-26。用户授权 API 总预算最多 20 元、使用现有 GitHub Linux 环境，并明确要求由助手补齐保留测试。实验结果另表记录，本文不预填成绩。

## 研究问题和范围

固定模型与一次修复机会，加入仓颉 1.0.5 官方文档检索是否改变本案例集的修复通过率？A 不提供文档，B 提供原生 BM25 的最多 3 条逐字摘录；其他提示、源码、题意、公开测试和原始诊断一致。文档增加的上下文长度也属于处理，不能单独归因于文档语义。

使用 20 个评估案例：16 个错误（语法、类型、作用域/API、逻辑各 4 个），另 4 个正确程序不调用模型，只检查回归。旧的 30 例清单及 10 个开发案例不变。独立的 `data/experiments/pilot-catalog.json` 在生成前把其中 7 个固定输出题改为显式参数函数，保持错误类别与原公开输出，支持有意义的保留输入。这是新版本评估集，不冒称原题结果。

本轮每错误每组仅生成一次，共 32 次；无第二轮、无择优、无人工修补、无重试。不同于开题协议的最多两轮主实验，本轮是第一轮完整配对先导实验；不据结果改提示词或补测后回选候选。

## 冻结和独立评分

- 生成前完成 20 个参考实现、112 次保留调用/断言，覆盖负数、零、正数、数组空值、范围端点、闰年世纪边界等。Bool 的两个输入已在公开测试出现，保留测试改变调用次序，不能声称新增其输入域覆盖。
- 参考实现、保留输入与预期输出在 `data/holdout/pilot-v1/`，由 AES-256-GCM 加密后上传密文；仓库只登记承诺摘要。解密钥匙仅送至受控 CI 验证步骤，绝不上传 DeepSeek API Key。模型生成进程只读取公开 freeze.json，不读取解密材料，不把保留测试、参考实现或结果加入提示。
- Linux 同一作业内用同一个不可变 Docker 镜像：先验证每例参考实现在公开及保留测试通过，原程序满足初始预期；4 个原始逻辑缺陷须被保留测试捕获。任何参考/初始检查失败，先停止且不付费生成。生成前失败修正须记录；不得在看到 A/B 答案后调题。
- 生成前冻结模型请求参数、提示词、顺序、案例/官方语料/保留材料 SHA-256、工具提交、镜像 ID。各对交替 A→B、B→A。原始提示、响应、时间、模型返回标识、token 用量、候选摘要均留存。
- 全部 32 个候选锁定并核对请求与源码摘要后，CI 才读取保留材料评分。不得把保留结果反馈到模型。原 main 由保留入口的词法扫描重命名，保留所有其他代码并添加独立调用；找不到唯一合法入口、保留函数缺失或不兼容均显式失败，不手动修补。
- 单文件 <=64 KiB/200 行；Linux 无网络受限容器编译和运行，使用既有资源限制与清理核对。编译和公开测试通过后再跑保留测试。工具/容器清理故障停止整次评估，不能误算程序失败。

## 模型和费用

`deepseek-flash`，关闭思考，temperature=0，top_p=1，max_tokens=2048，JSON 对象响应，非流式、90 秒超时、不调用工具。在线服务可能调整模型映射，返回标识照录，不能承诺精确版本或输出确定性。

仅本机向官方端点发送请求。总上限 20 元。按已查阅的官方高峰非缓存价格上界估计：输入每百万 tokens 2 元，输出 8 元；每次请求前按请求字节数加裕量预留，再按返回 usage 计算保守估计，缓存/优惠不用于放大预算。缺失 usage 或估计异常即停止后续调用；网络失败保留该次预留，不自动重试。估算不冒充账单实扣。原先 3 次开发调用不计入本实验结果。

来源：[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[请求接口](https://api-docs.deepseek.com/api/create-chat-completion/)。

## 预定结果口径

成功必须是候选有效、编译通过、公开测试和保留测试全过；无候选、格式非法、超时、失败和预算停止不能计成功。16 为两组固定分母。保留主表含编译、公开、保留三层结果、源码摘要、成本与失败原因，不删案例。

报告 A/16、B/16、均成功/仅A/仅B/均失败四格及 B−A 百分点；12 个编译错误、4 个逻辑错误分层描述，4 个正确程序另表。32 次调用不是 32 个独立案例。小样本、单次采样只支持本配置的探索性结论；无差异或 B 更差照实报告。没有独立学生试用或两名成员交叉复核，不能写成已经完成。

候选锁定后逐例检查是否删函数、硬编码或改变题意，观察另列，不在看过组别成绩后改自动判据。通过有限测试不等于证明程序普遍正确。测试由 Codex 辅助编写并做参考/缺陷检查，不虚构学生独立贡献或人员复核。

调用中断不能悄悄重新开始；保留账本和已收到响应，缺失项列明。工具缺陷修复须留下版本和旧记录，对两组统一复测，不新增候选。保留测试可在本轮全部候选锁定后作为复现材料解封；解封后不得再称其为后续实验的独立隐藏测试。
