# 从人工给文档到自动选择文档

上一轮人工给出节点和 Option 文档后，8 道节点游标题有 16/16 次通过。本轮评价面对混合任务的选择策略。先锁定规则，再编新题并锁定测试。规则开发者与编题者相同，因此仅作定向压力测试。

## 四种可执行策略

L 永远只给 LinkedList 的 26 条成员声明。A 总是额外附上上轮的节点属性卡和 Option 示例。S 只看错误函数源码，检测节点类型或返回节点的成员名。J 同时看源码和任务描述，按固定规则识别位置操作或忽略位置的要求。S、J 的实现不读题号、成绩或测试。每次选择都是 L 或 A，没有其他提示差异。

每道题对 L 和 A 各真正生成三次。在每个题号和重复编号上，S 与 J 直接使用其所选择条件的同一份候选及评分。这样任何两种策略选到完全相同的输入，成绩及 token 费用也完全相同。总计 32 题、192 次真实模型调用，回放 4 种策略，每种 96 次策略决策。不得将回放记为新的模型调用。

## 三类证据

- 24 道新题为主要结果。12 对题每对共用同一段错误函数。一道以给定位置为起点，另一道要求对整个序列计算或修改。左右方向、显式游标、由下标查找、弱线索和无关节点线索都纳入。每道题另有独立题意、公开期望及保留期望。不同题共享代码是有意设置的信息限制。
- 8 道旧题重新调用模型。复取上轮四类游标操作各一题，以及先前的两道书签和两道链表端点加权题。旧题不并入新题的主比较。
- 策略是否选中补充文档相对于“位置相关/整表”分层统计；位置相关描述不等于该题唯一正确解法必须用节点。实际价值看修复和用量。记录错误线索、两份文档均无效的题、持平和倒退。

主要比较为新题 J−L、J−A，辅以 S 与 L、A、J 的通过数和输入开销。按每对任务汇总净变化，列出改善/持平/下降的对数。逐题和重复保留，不把重复请求视作独立题。对同一回答按策略回放的结果强相关。试验不预设 J 必然优于总给文档。

固定 SDK 1.0.5、DeepSeek Flash、温度 0、关闭思考、无付费重试。每题每轮交换 L 和 A 的先后，奇偶题平衡。先在固定 Linux 容器核验全部参考解和原程序的公开及保留用例，再冻结请求，盲审候选后独立评分。失败候选保留分母。前期累计保守估算 5.096668 元，本轮最坏预留上限 10 元，含既有开发余量仍低于 20 元。
