# 同样两条样例，按题意选能更好发现错误吗？

2026-11-28，在 SDK 验收、模型调用及评分前冻结。本轮承接上一轮单元素样例无法区分首次与末次、只改一个与改全部的问题。主要终点是有保留错误的初稿被两条新增样例发现的题数。次要终点是实际模型修复以及按发现结果触发复查后的最终通过率。

## 材料与选择

主样本为 16 道新数组题，覆盖最长区间、限额更新、相邻跨阈值、双标记窗口四类契约。每类含四种题意、一个正确对照，其他初稿由研究者构造。另将上一轮全部 8 道数组题单列复验。不依据模型表现选题。每题有两个原公开输入、24 个可选诊断输入和 24 个独立保留输入。诊断输入长度均为 5、阈值相同。保留集包含空、单元素、其他长度及未展示的五元素输入，核对与本题原公开、整个诊断池及旧题历轮保留材料去重。

每题从同一个公开诊断池选两条。U 为固定种子的均匀无放回抽样。D 只读题目契约和几种常见的不同理解，枚举 276 个输入对，依次最大化能与正确契约区分的其他理解数量、所有理解两两可区分的数量。并列时按独立固定哈希顺序选。选择器不读取初稿实现、错误位置、初稿实际输出、保留数据或模型。两组都收到各自两条样例的输入、期望和初稿实测值，不显示策略名称。期望答案由研究者提供。两组均使用相同的复查指令、模型参数、输入条数及长度。

## 指标与执行

主样本与复验样本分开。先用固定 SDK 真实执行参考实现和初稿，核验参考公开、保留和整个诊断池的返回值与最终数组。用 24 个输入的初稿实测结果，对均匀选择的全部 276 种可能作精确平均，同时报告固定随机对的实测发现数。以独立保留集判断初稿对错，并报告正确初稿的误报。另报告相对原公开检查新发现的错误。按家族列出结果，不把诊断池内输入数当作独立程序数。

每题每组重新调用 DeepSeek Flash 两次，温度 0，顺序交错、第二遍倒序，共 96 次。所有生成都进入分母，先锁定并遮盖组别审阅源码，再在隔离容器检查原公开、诊断池和保留测试。修复成功要求编译、原公开和全部保留检查通过；两个所选样例不进入主评分。单列“所选样例通过但保留失败”和初稿由对变错的次数。在同批回答上回放仅当原公开或所选样例失败时才调用的规则，记录调用量和最终通过数。若检测提升而修复持平，分别报告两个指标。研究者自编题和竞争解释可能使定向选择获益，结果只适用于测试的材料。研究预算从累计保守估算 7.404568 元起算，本批最多预留 5 元。
