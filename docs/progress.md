## 第十四轮记录（验证中断与登记资源恢复，2026-10-24）

- 新增 Linux 稳定文件 FD + `flock`：同一规范工作区的探针、Web 公开验证与 CLI 不会跨进程同时运行；锁冲突明确拒绝，不终止原任务。Docker 子进程继承 FD，父进程死亡后仍在进行的客户端继续持锁，直到自身结束。缺 `flock`、链接/硬链接、目录或 inode 变化均拒绝执行，不降级成无锁运行。
