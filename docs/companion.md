# 本地兔耳角色

2026-11-16 将用户确认的白粉垂耳兔女生接入教程欢迎区和 AI 页引导卡片。保留第一版平贴的垂耳形状，眼睛为黑色线条下方的两格灰色，修正的是这两格而不是眉毛。现有方块场景与侧栏图标保留。

默认静止；点击挥手约 3 秒，再次点击停止。切页、后台或系统减少动态效果时停止动画；减少动态效果下点击仅显示文字问候。角色没有模型调用、聊天能力或密钥读取行为。

## 安装与来源

本机已安装 `web/assets/local-companion/bunny-still.png`（280×350 PNG）和 `bunny-wave.webp`（60 帧、每帧 50 ms、透明 WebP）。页面按两个文件是否同时存在决定加载卡片；全新克隆没有这些文件时保留完整工作台，不显示空角色。预览服务仅开放这两个图片文件及配套 CSS/JS，不公开整个目录。

皮肤来源：[Laby 皮肤页面](https://laby.net/skin/f38a5647610d68d7d1c3ecbdf341012e)，纹理标识 `7b0376517e717f04eed47835c64f66b8e0c89af20a8cc9343394f12d813d79dc`。尚未核实可公开再分发的授权，不能视为开源素材。源皮肤、衍生图和含角色截图仅保存在本机，不随公开仓库提交。两平台提交接入代码及过程记录；公开发布角色前须核实许可或换为可分发的原创素材。

本机制作源位于项目上级 `output/bunny-preview/render_bunny_lop_eyes.py`，读取同目录 `bunny-skin.png`；通过 NumPy/Pillow 软件渲染既有模型。静态图取 idle 第 7 帧，动画取 wave 第 0–59 帧；576×576 透明输出裁剪框为 `(165,170,445,520)`，不改写源皮肤。换图时保留文件名、透明背景、尺寸和动画时长，再刷新页面。移走两个安装文件即可取消显示，无需改主页面。
